# Game Fakultas Sihir UGM

Proyek UAS Mata Kuliah Pemrograman Berorientasi Objek (PPBO).

## Deskripsi

Game RPG bertema Universitas Gadjah Mada yang mengangkat konsep dunia sihir di lingkungan kampus. Pemain dapat menjelajahi area permainan, melawan monster, mengumpulkan item, dan meningkatkan perlengkapan karakter.

## Teknologi

* Java
* JavaFX
* FXGL
* Maven

## Status Pengembangan

Project masih dalam tahap pengembangan dan penyempurnaan fitur.

## Repository

Repository ini digunakan untuk kolaborasi dan version control selama proses pengembangan proyek.

## Cara Menjalankan

1. Clone repository.
2. Buka project menggunakan IntelliJ IDEA.
3. Pastikan Maven melakukan download dependency.
4. Jalankan `FakultasSihirApp.java`.
